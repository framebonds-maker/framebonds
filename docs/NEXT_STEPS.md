**Brand Philosophy (Volume I):**

- Website is first portfolio piece—must silently prove quality before words are read
- Emotional promise: "We care about details. We respect your brand. We think before we create."
- 12 constitutional non-negotiables (Trust > Revenue, Quality non-negotiable, Paid to Think, etc.)

**Visual Language (Volume II):**
- Color: Neutral interface (deep charcoal, off-white); portfolio is visual hero; accents for CTAs only
- Typography: 2-font maximum; 6-level hierarchy; editorial, cinematic, modern aesthetic
- Spacing: Whitespace as luxury; content containers with max-widths; gallery principle
- Components: Reusable system; every element belongs to FrameBonds; no templates
- Media: Cinematic standard (luxury campaigns, Netflix quality); ruthless curation; museum presentation
- Design tokens: Everything systematic (colors, spacing, shadows, motion, states, accessibility)

**Page Architecture (Volume III):**
- Homepage: 9 sections (Hero → Portfolio → About → Services → Process → Why → Results → CTA → Footer)
- Visitor journey: 6 stages (Capture → Curiosity → Capability → Remove Doubt → Build Trust → Action)
- Storytelling: Progressive disclosure; emotional + visual rhythm; momentum maintained throughout
- Content ratio: 60% visuals, 25% headlines, 15% body text
- Portfolio: 6–8 projects (quality > quantity); editorial grid; museum-rule spacing
- Process: 5-step (Discovery → Planning → Production → Post → Delivery); transparent, not overwhelming
- CTA strategy: Progressive commitment (Low early → Medium middle → High final)
- Three-click rule: Visitor achieves 3 goals in 3 interactions (Understand → See quality → Know how to contact)
- Trust signals: Authentic testimonials, real outcomes, case studies, no fabrication

**Decision Framework (Applied Across All Volumes):**
- User experience > Trust > Clarity > Performance > Beauty
- Quality non-negotiable; simplicity prioritized over complexity
- Specificity over generic marketing language
- Authenticity over impressiveness
- Long-term credibility over short-term attention
